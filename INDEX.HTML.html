📝 ઝડપી નોંધો

⚡ ભૌતિકશાસ્ત્ર — ઝડપી પુનરાવર્તન

SI units: length = મીટર (m), mass = kilogram (kg), time = સેકન્ડ (s).

Speed: distance ÷ time.

Velocity: displacement ÷ time.

🧪 રસાયણશાસ્ત્ર — ઝડપી પુનરાવર્તન

Mole: amount of substance containing Avogadro number of કણો.

Atomic number: number of પ્રોટોન in an atom.

Mass number: પ્રોટોન + ન્યુટ્રોનનો સરવાળો.

Avogadro's number: 6.022 × 10²³.

📐 ગણિત — ઝડપી પુનરાવર્તન

Set: સુવ્યાખ્યિત વસ્તુઓનો સંગ્રહ.

Function: દરેક ઈનપુટ માટે એક જ આઉટપુટ આપતો સંબંધ.

Quadratic equation: ax² + bx + c = 0 (a ≠ 0).

sin²θ + cos²θ = 1 — મૂળભૂત ત્રિકોણમિતિ સૂત્ર.

🧬 જીવવિજ્ઞાન — ઝડપી પુનરાવર્તન

કોષ: સજીવોનો મૂળભૂત રચનાત્મક અને કાર્યાત્મક એકમ.

વર્ગીકરણ ક્રમ: Kingdom → Phylum → Class → Order → Family → Genus → Species.

Photosynthesis: 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ (સૂર્યપ્રકાશની હાજરીમાં).

🔤 English — Quick Revision

Noun: a word that names a person, place, thing, or idea.

Tenses: Present, Past, Future — each with Simple, Continuous, Perfect, Perfect Continuous.

Active/Passive Voice: Active — subject does the action; Passive — subject receives the action.

🕉️ સંસ્કૃત — ઝડપી પુનરાવર્તન

સંધિ: બે વર્ણોના મેળાપથી ઉત્પન્ન થતો ફેરફાર.

કારક: વાક્યમાં ક્રિયાપદ સાથે નામનો સંબંધ દર્શાવતું તત્વ (કર્તા, કર્મ, કરણ વગેરે).

ધાતુરૂપ: ધાતુ (verb root) પરથી બનતા ક્રિયાપદના રૂપો.

💻 કમ્પ્યુટર — ઝડપી પુનરાવર્તન

Hardware: કમ્પ્યુટરના ભૌતિક ભાગો (CPU, Keyboard, Monitor વગેરે).

Software: કમ્પ્યુટરને ચલાવતા પ્રોગ્રામ્સ અને સૂચનાઓનો સમૂહ.

Algorithm: સમસ્યાના ઉકેલ માટેના ક્રમબદ્ધ પગલાંઓ.
